# Evidencia anterior al punto cero (julio 2026)

Estos artefactos son de julio de 2026, **anteriores al punto cero del historial delta**
(`openspec/changes/archive/BASE-000-punto-cero.md`, F0/T03). Ningún escenario de
`openspec/specs/` los cita.

`evidencia/README.md` exige que cada archivo pruebe UN criterio citado por un test o un
scenario. Estos no cumplen esa regla, y no se pueden reconstruir sin inventar la cita.
Por eso se archivan aquí en vez de borrarse: sirven como registro visual de las pantallas
`f1-b11` (sospechas, necesidades, gate de cambio) y `f1-b12` (traza `CHG-0003`) tal como
estaban antes de F0, pero **no son evidencia válida** en el sentido de `NORMATIVA/VALIDACION.md`.

Se resuelve en F4, cuando la evidencia pase a vivir en la BD de Quipu y `evidencia/`
quede deprecado en bloque.
